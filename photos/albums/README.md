# Album sleeves

Twenty two covers, collaged behind the contact room. Each `<figure>` in
`index.html` names its file; a missing file removes its whole figure, so the
pile still composes if one is dropped.

Sizes, angles and depths all disagree on purpose. Some are torn (`lp--tear`),
some punched out as the record itself (`lp--round`), some blended into what
they overlap (`lp--blend`). Grain sits over the whole pile.

Square, 400x400 or larger. Cover art belongs to the labels, so it stays
decorative here: no titles printed, no artist credits, nothing sold.
