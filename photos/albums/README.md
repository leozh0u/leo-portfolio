# Album sleeves

The contact room draws all thirteen sleeves in CSS, so the page is complete with
no files in here at all. Each drawing uses that record's own palette and prints
its title.

To swap in a real cover, drop a JPEG in this folder named after its slug. The
`<img>` in `index.html` paints straight over the drawing. If the file is missing
the image removes itself and the drawing stands, so a half-filled folder is fine.
